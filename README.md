# NR Store

একটা মিনি অ্যাপ স্টোর ওয়েবসাইট — ইউজাররা অ্যাপ ব্রাউজ করে, সার্চ করে, ডাউনলোড করতে পারবে। GitHub Pages-এ ফ্রি হোস্ট করা হয়েছে।

## প্রজেক্ট স্ট্রাকচার

```
nr-store/
├── index.html      → মূল পেজ (HTML স্ট্রাকচার)
├── style.css       → সব ডিজাইন/স্টাইলিং
├── script.js       → অ্যাপ লিস্ট লোড করা, সার্চ, Firebase সংযোগ
└── README.md       → এই ফাইলটা
```

## এখন পর্যন্ত যা তৈরি হয়েছে

- [x] উপরের অ্যাপ বার (লোগো + নোটিফিকেশন আইকন)
- [x] সার্চ বক্স
- [ ] ফিচার্ড ব্যানার
- [ ] ক্যাটাগরি ট্যাব
- [ ] অ্যাপ কার্ড গ্রিড (হোম পেজের মূল অংশ)
- [ ] অ্যাপ ডিটেইল পেজ
- [ ] Firebase-এর সাথে সংযোগ (আসল ডেটা দেখানো)
- [ ] অ্যাডমিন "Add New App" ফর্ম

GitHub Pages চালু করার পর এখানে লাইভ লিংক বসবে:
```
https://<your-username>.github.io/nr-store/
```

## ডিপ্লয় করার নিয়ম

নতুন ফাইল বা পরিবর্তন এলে:
1. GitHub রিপোতে গিয়ে পরিবর্তিত ফাইলটা খুলুন
2. পেন্সিল (Edit) আইকনে চেপে নতুন কোড পেস্ট করুন
3. নিচে "Commit changes" চাপুন
4. ১-২ মিনিটের মধ্যে লাইভ সাইটে পরিবর্তন দেখা যাবে (GitHub Pages স্বয়ংক্রিয়ভাবে আপডেট করে)

## ব্যাকএন্ড (পরের ধাপে যোগ হবে)

- **ডেটাবেজ:** Firebase Realtime Database — অ্যাপের তালিকা, ক্যাটাগরি, ডাউনলোড সংখ্যা সেভ থাকবে
- **APK ফাইল হোস্টিং:** GitHub Releases — প্রতিটা অ্যাপের আসল APK ফাইল আলাদা রিপোতে Release হিসেবে আপলোড করা হবে, আর Firebase-এর `apk_url` ফিল্ডে সেই লিংক বসানো হবে

## ডাটাবেজ স্ট্রাকচার (পরিকল্পনা)

```
apps/
  {appId}/
    name, developer, category, description,
    icon_url, apk_url, version, size_mb,
    downloads_count, rating

categories/
  {categoryId}/
    name
```
